# ym_to_db
Выгрузка данных из Яндекс Метрики в базу данных PostgreSQL.

## Описание

Программа автоматически загружает данные о визитах из Яндекс Метрики и сохраняет их в базу данных PostgreSQL. Поддерживается загрузка следующих полей:

- Идентификаторы визита и клиента (visitID, clientID, watchIDs)
- Информация о визите (дата, продолжительность, отказы, просмотры страниц)
- URL (начальный, конечный, реферер)
- Устройство и операционная система
- UTM-метки (campaign, source, medium, content, term)
- Источники трафика (Direct, Referal, Search Engine, Adv Engine)
- Цели (ID и время достижения)
- Электронная коммерция (покупки, продукты, доход)
- Показы товаров
- География (город)

## Требования

- Python 3.7+
- PostgreSQL база данных
- Токен доступа к API Яндекс Метрики
- ID счетчика Яндекс Метрики

## Установка

### 1. Установка зависимостей на macOS

```bash
# Установка Python (если еще не установлен)
# Рекомендуется использовать Homebrew
brew install python3

# Установка зависимостей проекта
pip3 install -r requirements.txt
```

### 2. Настройка конфигурации

Скопируйте файл `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте файл `.env` в текстовом редакторе и заполните необходимые параметры:

```bash
# Настройки базы данных PostgreSQL
DB_HOST=ashoxitalit.beget.app          # Адрес сервера БД
DB_PORT=5432                            # Порт (обычно 5432)
DB_NAME=default_db                      # Имя базы данных
DB_USER=cloud_user                      # Имя пользователя
DB_PASSWORD=your_password_here          # ЗАПОЛНИТЕ: Пароль от БД

# Настройки Яндекс Метрики
YM_TOKEN=your_yandex_metrika_oauth_token_here    # ЗАПОЛНИТЕ: OAuth токен
YM_COUNTER_ID=your_counter_id_here               # ЗАПОЛНИТЕ: ID счетчика

# Параметры выгрузки данных
START_DATE=2024-01-01                   # Начальная дата (формат: YYYY-MM-DD)
END_DATE=2024-12-31                     # Конечная дата (формат: YYYY-MM-DD)
```

#### Где взять токен Яндекс Метрики:

1. Перейдите на страницу: https://oauth.yandex.ru/authorize?response_type=token&client_id=3c4ac1bc90984e03bc8936d6f7748c12
2. Разрешите доступ к Яндекс Метрике
3. Скопируйте полученный токен в параметр `YM_TOKEN`

#### Где взять ID счетчика:

1. Войдите в Яндекс Метрику: https://metrika.yandex.ru
2. Выберите нужный счетчик
3. ID счетчика указан в URL (например, `https://metrika.yandex.ru/dashboard?id=12345678` - ID: 12345678)

## Использование

### Запуск программы

```bash
python3 main.py
```

### Что происходит при запуске:

1. Программа проверяет конфигурацию
2. Подключается к базе данных PostgreSQL
3. Создает таблицу `yandex_metrika_visits` (если она не существует)
4. Отправляет запрос на выгрузку данных в Яндекс Метрику
5. Ожидает обработки запроса (может занять несколько минут)
6. Загружает данные из Яндекс Метрики
7. Сохраняет данные в базу данных
8. Выводит результаты и логи

### Логи

Программа создает файл `ym_to_db.log` с подробными логами работы. В случае ошибок проверьте этот файл.

## Структура базы данных

Программа автоматически создает таблицу `yandex_metrika_visits` со следующими полями:

- `id` - автоинкрементный первичный ключ
- `visit_id` - ID визита
- `client_id` - ID клиента
- `watch_ids` - ID просмотров
- `visit_date` - дата визита
- `is_new_user` - новый пользователь (0/1)
- `start_url` - начальная страница
- `end_url` - конечная страница
- `visit_duration` - продолжительность визита (секунды)
- `bounce` - отказ (0/1)
- `page_views` - количество просмотренных страниц
- Поля UTM-меток: `utm_campaign`, `utm_source`, `utm_medium`, `utm_content`, `utm_term`
- Поля источников трафика: `traffic_source`, `referer`, `direct_platform`, `search_engine_root`, и др.
- Поля целей: `goals_id`, `goals_date_time`
- Поля электронной коммерции: `purchase_id`, `purchase_revenue`, `products_id`, и др.
- Технические поля: `device_category`, `operating_system_root`, `region_city`
- `created_at` - время добавления записи в БД

## Обработка ошибок

Программа включает обработку следующих типов ошибок:

- **Ошибки конфигурации**: Проверка наличия всех обязательных параметров
- **Ошибки подключения к БД**: Проверка доступности базы данных
- **Ошибки API Яндекс Метрики**: Обработка ошибок при запросе данных
- **Таймауты**: Автоматическое ожидание обработки запроса (до 10 минут)
- **Ошибки вставки данных**: Обработка ошибок при записи в БД

При возникновении ошибок программа выводит понятное сообщение и записывает детали в лог-файл.

## Устранение проблем

### Ошибка "Missing required environment variables"
- Проверьте, что файл `.env` создан и все обязательные поля заполнены

### Ошибка подключения к базе данных
- Проверьте правильность параметров `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`
- Убедитесь, что сервер базы данных доступен

### Ошибка API Яндекс Метрики
- Проверьте правильность токена `YM_TOKEN`
- Проверьте правильность `YM_COUNTER_ID`
- Убедитесь, что у токена есть права доступа к счетчику
- Если получаете ошибку 404, убедитесь что используется актуальная версия программы (API endpoint должен использовать `/logrequests` с 's' на конце)

### Таймаут при обработке запроса
- Попробуйте уменьшить период выгрузки (разбить на более короткие промежутки)
- Проверьте интернет-соединение
